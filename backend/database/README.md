# سكريبتات إعداد قاعدة البيانات

هذا المجلد يحتوي على سكريبتات SQL لإعداد قاعدة البيانات.

## 📋 السكريبت الرئيسي (مستحسن)

### ✨ SETUP_ALL.sql - الإعداد الشامل الكامل

هذا السكريبت يعمل **كل شيء** دفعة واحدة:

✅ إنشاء جدول المشتريات (purchases)
✅ إنشاء جدول المصروفات (expenses)
✅ إنشاء 3 مستخدمين Admin بجميع الصلاحيات

**الاستخدام:**

1. افتح **phpMyAdmin** (http://localhost/phpmyadmin)
2. اختر قاعدة البيانات: **coffee_shop**
3. اضغط على تبويب **SQL**
4. افتح الملف: `SETUP_ALL.sql`
5. انسخ **كل** محتويات الملف
6. الصقه في phpMyAdmin
7. اضغط **Go** أو **تنفيذ**

**معلومات تسجيل الدخول بعد التشغيل:**

| اسم المستخدم | كلمة المرور | الاسم الكامل |
|--------------|-------------|--------------|
| kareem       | 123456      | كريم خميس    |
| admin        | 123456      | المدير العام |
| manager      | 123456      | مدير المقهى  |

جميع المستخدمين لديهم **جميع الصلاحيات**!

## 📝 السكريبتات الفردية

إذا كنت تريد تشغيل كل جزء على حدة:

### 1. setup_purchases_table.sql
ينشئ جدول المشتريات فقط.

**الأعمدة:**
- supplier_name - اسم المورد
- item_description - وصف الصنف
- quantity - الكمية
- unit_price - سعر الوحدة
- total_amount - المبلغ الإجمالي
- purchase_date - تاريخ الشراء
- notes - ملاحظات

### 2. setup_expenses_table.sql
ينشئ جدول المصروفات فقط.

**الأعمدة:**
- category - فئة المصروف
- description - وصف المصروف
- amount - المبلغ
- expense_date - تاريخ المصروف
- notes - ملاحظات

### 3. create_admin_user.sql
ينشئ مستخدمين Admin فقط.

**المستخدمين المنشأين:**
- kareem / 123456
- admin / 123456
- manager / 123456

## 🚨 حل المشاكل الشائعة

### المشكلة: "Unknown column 'supplier_name'"
**الحل:** شغّل سكريبت `SETUP_ALL.sql` - الجدول غير موجود أو به أعمدة خاطئة

### المشكلة: "Invalid credentials"
**الحل:** شغّل سكريبت `SETUP_ALL.sql` - لم يتم إنشاء المستخدم بشكل صحيح

### المشكلة: "Table 'purchases' doesn't exist"
**الحل:** شغّل سكريبت `SETUP_ALL.sql`

### المشكلة: "حدث خطأ في تحميل التقرير"
**الحل:** شغّل سكريبت `SETUP_ALL.sql` - الجداول غير موجودة

## ⚠️ ملاحظات مهمة

1. **النسخ الاحتياطي:**
   - قبل تشغيل السكريبت، اعمل نسخة احتياطية لقاعدة البيانات
   - السكريبت يحذف الجداول القديمة (DROP TABLE)

2. **كلمة المرور:**
   - جميع المستخدمين يستخدمون كلمة المرور: **123456**
   - تم تشفيرها بـ bcrypt (10 rounds)
   - يمكنك تغييرها لاحقاً من واجهة النظام

3. **الصلاحيات:**
   - جميع المستخدمين لديهم **كل** الصلاحيات
   - بما فيها: can_add_expenses (مهم للمشتريات!)

4. **قاعدة البيانات:**
   - تأكد من اختيار قاعدة البيانات الصحيحة: **coffee_shop**
   - إذا كان اسم قاعدة البيانات مختلف، غيّره في phpMyAdmin
